# Словарь терминов

Термины вводятся при первом появлении в самих документах; здесь они собраны
в одном месте, чтобы не искать.

---

## Словарь терминов

| Термин | Простое объяснение |
|---|---|
| Feature | входной признак модели, например пробег |
| Target | значение, которое модель учится предсказывать |
| Inference | применение уже обученной модели |
| Artifact | сохранённый файл модели и его metadata |
| Baseline | простое решение, которое ML обязан победить |
| Leakage | модель получила информацию, которой не будет в реальности |
| Outlier | статистически необычная строка |
| Median | значение, относительно которого половина ниже, половина выше |
| MAD | типичное абсолютное отклонение от медианы |
| MAPE | средняя относительная ошибка в процентах |
| MAE | средняя абсолютная ошибка в исходных единицах |
| R² | насколько модель объясняет изменчивость target |
| Cross-validation | несколько циклов train/test на разных частях данных |
| Holdout | часть данных, которую не трогают до финальной проверки |
| Out-of-time | проверка на более новых данных |
| Residual | разница между фактом и прогнозом |
| Quantile | граница, ниже которой находится заданная доля наблюдений |
| Precision | доля настоящего fraud среди поднятых тревог |
| Recall | доля пойманного fraud среди всего fraud |
| False positive | честное объявление ошибочно помечено |
| False negative | fraud пропущен |
| Idempotent | повторный запуск не создаёт неконтролируемые дубли |
| Append-only | журнал наблюдений растёт новыми строками; старые наблюдения не удаляются |
| Human-in-the-loop | человек проверяет и улучшает автоматическое решение |
